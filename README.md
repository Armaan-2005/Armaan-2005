## 🏆 Practical Outcomes

My project work has given me experience in:

- **Infrastructure as Code:** organizing Terraform configurations into reusable modules and managing remote state in S3.
- **Cloud networking:** connecting VPCs, subnets, security groups, EC2, load balancers, and RDS.
- **CI/CD:** defining Jenkins and GitLab CI/CD workflows for infrastructure and container-image tasks.
- **Containerization:** building Docker images and publishing them to Docker Hub.
- **Linux administration:** managing services, using SSH, troubleshooting connectivity, and running server commands.
- **Monitoring:** configuring Prometheus and Grafana to visualize metrics.
- **Configuration management:** practising Ansible inventories, playbooks, and remote task execution.
